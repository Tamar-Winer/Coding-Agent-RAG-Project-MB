# Coding Agent RAG - Project 3

מערכת RAG חכמה מבוססת LlamaIndex לניהול ותשאול תיעוד פרויקטים.

## יכולות המערכת:
- סריקה ועיבוד מסמכי MD וטקסט.
- אינדוקס וקטורי ב-Pinecone.
- חיפוש סמנטי תומך עברית באמצעות Cohere.
- ממשק צ'אט מעוצב ב-Gradio.

## התקנה:
1. התקן דרישות: `pip install -r requirements.txt`
2. הגדר מפתחות בקובץ `.env`.
3. הרץ את `app.py`.
